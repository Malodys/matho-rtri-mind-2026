# 问题 3「风味与风味指纹生成」方法与产物说明

> 全部数值口径：**统一 log10(mg/L)**（经 `scripts/data_contract.py` 的 `to_unified_scale()` 取数）。1.csv 为混合标度，全流程未做任何 `10**x` 逆变换；缺陷阈值一律取 `defect_table()` 的 `log10_threshold`。

## 1 方法定义式

### 1.1 全局高斯 Copula（结构层）

对 250×231 统一矩阵逐列取范德瓦登正态分数 `z_j = Φ⁻¹((rank_j-0.5)/250)`，计算 231×231 Pearson 相关矩阵 `R`，再经岭正则（ridge=1e-3）与特征值下截断保证正定并 Cholesky 分解：

```
z_i = L · ε_i,  ε_i ~ N(0, I_231),  R = LLᵀ,  L = chol(R + ridge·I)
```

### 1.2 风格条件边际（边际层）

风格 `s` 的条件边际为**混合 CDF**，实现取其广义逆：

```
F_s(x) = (1-λ_s)·F_global(x) + λ_s·F_s^emp(x)
λ_s    = n_s / (n_s + 10)          # 小样本向全局边际收缩
u_j    = Φ(z_j)                   # Copula 给出的第 j 维分位水平
v_j    = F_s^{-1}(u_j)            # 映回风格条件边际
```

因混合 CDF 的广义逆是阶梯函数，`KS(F_s, F_s^emp) = (1-λ_s)·KS(F_global, F_s^emp)`，收缩带来的边际偏差可精确刻画（这是本实现选「CDF 广义逆」而非「分位空间线性混合」的原因；后者实测 KS 中位数高出约 0.05–0.09，见 `q3_generate.py --marginal-mode quantile`）。

**风格内常量列规则**：若某化合物在该风格内极差为 0（多为 LOD 下限，如 Kriek 的 `X4VG` 恒为 −2.0132），该列取 `λ_c = 1` 直接保留风格常量值，避免把全局噪声混入风格常量。涉及列数：

| 风格 | n_s | λ_s | 风格内常量列数 |
|---|---|---|---|
| Tripel | 28 | 0.7368 | 0 |
| Kriek | 10 | 0.5000 | 3 |
| Lambic | 11 | 0.5238 | 4 |
| Blond | 31 | 0.7561 | 0 |
| Strong ale | 18 | 0.6429 | 0 |
| Hoppy | 17 | 0.6296 | 0 |
| Dubbel | 10 | 0.5000 | 1 |
| Saison | 10 | 0.5000 | 0 |

## 2 缺陷约束规则

| key | 化合物列 | log10 阈值 | 约束口径 |
|---|---|---|---|
| dms | `DMS` | −1.7632（17.25 µg/L） | 拒绝-重抽，硬约束 ≤ 阈值−0.02 |
| diacetyl | `X2.3.butanedione` | −0.5240（0.29925 mg/L） | 同上 |
| 4vg | `X4VG` | −0.6854（0.206333 mg/L） | 同上 |
| t2n | `X.E..2.nonenal` | **文件 8 无阈值** | 以「迁移后不恶化」相对约束兜底 |

机制：先从全局 Copula 抽候选池 → 按三项阈值做**拒绝-重抽**（row 级，保留化合物间相关结构）→ 兜底为单调压缩修复（`value ← min(value, 阈值−margin)`）→ 最后硬裁剪保证违规数为 0。`margin = 0.02`（log10 口径）留安全余量。

### 2.1 约束会把缺陷列边际系统性压低（关键结论）

**这是约束的必然代价，不是生成器缺陷。**「拒绝-重抽」把分布条件化到缺陷项的低尾，因此**有约束谱**的缺陷列中位数被系统性压低。以 Tripel 为例：

### 2.2 两版谱的用途不同（务必在论文中声明）

* **无约束谱 `<style>_unconstrained.csv`** —— 代表该风格的**真实化学画像**：边际对齐真实样本（KS 中位数 0.065–0.176），缺陷超标率与真实样本同量级。
* **有约束谱 `<style>_synthetic.csv`** —— 代表**合规（零超标）画像**：三项有阈值的缺陷超标样本数恒为 0，但代价是缺陷列边际被压低。

两版由**同一次候选抽样**产生（同种子、同 Copula、同条件边际、同候选池），唯一差别是是否施加缺陷约束，因此可直接做配对比较。

* **KS 中位数的解读**：KS 参照系是该风格的真实样本，样本量仅 10–31，两样本 KS 在原假设下的中位数本身就有 0.128–0.218；有约束版的 KS 中位数与之相当（Kriek/Lambic 甚至低于原假设中位数），说明该量级由**参照样本量**决定，而非生成器还原度不足。无约束版 KS 中位数 0.065–0.176 才是生成器还原度的直接证据。

「目标」列是**目标条件边际的理论超标率** `1 − M_s(thr)`，即`(1−λ)·全局超标率 + λ·风格真实超标率` 的精确值。无约束生成的实测超标率与该理论值的偏差：DMS ≤ 6.6 个百分点、Diacetyl ≤ 4.4 个百分点、4-VG ≤ 3.2 个百分点 —— 说明**生成器忠实复现了它自己的目标边际**。

* 大样本风格（Blond n=31、Tripel n=28）差异很小：DMS 90.0% vs 真实 96.8%、Tripel 82.0% vs 真实 89.3%。
* 小样本风格差异较大（Kriek n=10：真实仅 1/10 款 DMS 超标 → 10.0%，而 λ=0.5 的收缩把目标拉到 38.6%）：n=10 时「1/10 超标」这一估计本身方差极大，收缩到全局率（67.2%）是贝叶斯式的合理折中，而不是生成器还原错误。
* **有约束列恒为 0%**，这是约束的结果（见 §2.1）。

## 4 KS 超过 0.15 的说明与收紧尝试

部分风格的有约束 KS 中位数 > 0.15。按验收要求做了两项尝试：

**(a) 收紧 λ**（λ×1.25 / λ×1.5，λ 上限 1.0）：

| 风格 | λ×0.5 | λ×0.75 | λ×1.0(题面口径) | λ×1.25 | λ×1.5 |
|---|---|---|---|---|---|
| Kriek | 0.2360 | 0.2120 | 0.1800 | 0.1440 | 0.1200 |
| Lambic | 0.2531 | 0.2171 | 0.1800 | 0.1455 | 0.1251 |
| Saison | 0.2800 | 0.2360 | 0.2120 | 0.1880 | 0.1520 |
| Tripel | 0.1789 | 0.1574 | 0.1494 | 0.1351 | 0.1360 |

**(b) 增加采样量**（n=250 → 500）：KS 中位数基本不变（变化 ≤ 0.014），因为 KS 的噪声下限由**参照样本量**（风格真实样本 10–31 条）决定，而不是生成样本量。

**结论**：主结果保留题面拍板的 λ = n/(n+10)；若下游场景更看重「贴近风格真实边际」而非「小样本稳健性」，可用 λ×1.25（此时全部风格 KS 中位数 ≤ 0.19、Saison 降至 0.188）。完整扫描见 `lambda_sensitivity.csv`。

## 5 跨风格迁移 Pils/Lager → Tripel（Step 7）

* 源样本：真实 Pils/Lager **11** 条 × 231 维；目标边际：Tripel 条件边际，λ = 0.7368
* 方法：**秩-分位映射**（Iman-Conover 边际替换）——每列把源样本的秩映射到目标风格条件分位，列内秩不变 ⇒ 相关结构保持；再施加同一套缺陷约束（三项阈值 + 四项「不恶化」）
* 缺陷项核验：共 44 条（11 样本 × 4 项），**恶化 0 条（必须为 0）**，**迁移后超标 0 条（必须为 0）**
* 相关结构保持：Spearman ρ 平均绝对偏差 **0.022090**（上限 0.05），最大单对偏差 0.6306；Pearson 口径平均偏差 0.1718

## 9 已知局限

1. **n<5 的风格默认不生成**：Faro（n=3）、Brut（n=4）、Scotch（n=5）、Flanders old brown（n=5）未生成。原因：λ = n/(n+10) 分别为 0.23/0.29/0.33/0.33，条件边际几乎退化为全局边际，生成的「风格特征」不可靠；且 n≤5 时经验分布的边际 KS 参照本身没有统计意义。脚本对 n<5 风格默认跳过，如确需生成请显式指定并自行解读。
2. **约束压低缺陷列边际**（见 §2.1）：有约束谱不能直接当作「风格真实化学画像」使用，二者用途须严格区分。
3. **边际由全部 250 个真实样本定义**，因此 KS 度量衡量的是「与真实分布的对齐度」（分布匹配），不是对未见数据的泛化能力，该指标偏乐观。
4. **边际取自经验分布的原子**：条件边际是全局与风格经验分布的混合，生成值中有 (1−λ) 比例取自真实样本的经验分位（不外推出真实取值域），好处是「不会生成现实中不存在的化合物浓度」，代价是存在与真实样本的数值重合。
5. **t2n（E-2-nonenal）无绝对阈值**：文件 8 未提供该化合物的感官阈值，生成阶段无法施加绝对约束，只能在迁移阶段以「不恶化」相对约束兜底，论文须声明该缺口。
6. **感官画像依赖 Q1**：见 §6，当前状态 `pending_q1`。
7. **相关结构保持度的参照噪声**：迁移前后 Spearman ρ 的平均绝对偏差 0.022090（<0.05）虽已达标，但该量在 n=11 的样本上估计本身不稳定，最大单对偏差达 0.6306（来自缺陷列被压缩到同一阈值造成的并列值）。
