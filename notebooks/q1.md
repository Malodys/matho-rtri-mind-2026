# Q1 方案与结果

## 提交代码职责

- `scripts/q1_entry.py`：问题1入口，只编排运行、保存和汇总。
- `scripts/q1_models.py`：模型定义、参数网格、分组Extra Trees和单指标GBR。
- `scripts/q1_evaluation.py`：数据契约、代理等级、统一评价和已完成运行的读取检查。
- `scripts/q1_visualize.py`：单模型解释图与多模型比较图；不负责选择训练数据。

## 代码入口

```bash
python scripts/split_dataset.py --seed 0
python scripts/q1_entry.py \
  --split-dir data/splits/seed_0 \
  --output-dir reports/modeling/entry_v1
```

可以分模型运行，每个命令自动保存到 `reports/modeling/q1_runs/<model>/`：

```bash
python scripts/q1_entry.py --models global_mean
python scripts/q1_entry.py --models ridge
python scripts/q1_entry.py --models pls2
python scripts/q1_entry.py --models multitask_elastic_net
python scripts/q1_entry.py --models global_extra_trees
python scripts/q1_entry.py --models grouped_extra_trees
python scripts/q1_entry.py --models independent_gbr
```

全部完成后统一汇总：

```bash
python scripts/q1_entry.py --collect \
  --runs-dir reports/modeling/q1_runs \
  --output-dir reports/modeling/q1_entry_v1
```

`--collect` 不重新训练；它检查各模型是否有完整的 `75×50` 预测，再用统一评估器重算总表和比较图。

## 数据与划分

- 输入：02处理后的 `chem_log10_matrix_v1.csv`，排除4个公式未验证的 `*_sum` 派生列，使用227个预测变量。
- 输出：4.csv中的50个连续标准化感官标签。
- 外层划分：固定seed 0的70%/30%留出集，175个训练样本、75个测试样本。
- 划分时按风格分层，保证22个风格在两边都出现；风格不进入模型。
- 调参：只在175个训练样本中进行随机5折KFold。
- 75个测试样本仅评估一次。

## 模型

| 模型 | 训练单位 | 共享方式 | 使用意图 |
|---|---|---|---|
| 全局均值 | 每个指标一个常数 | 无 | 仅作无化学信息基线 |
| Ridge | 50个指标同时传入 | 共用正则强度，但各目标系数独立 | 处理 p>n 和强共线性的稳定线性主线 |
| PLS2 | 50目标联合回归 | 共享监督潜变量 | 利用感官指标间的相关结构 |
| Multi-task Elastic Net | 50目标联合回归 | 共享行稀疏的特征选择 | 获得更可解释的共同化学特征集 |
| 全局Extra Trees | 50目标联合回归 | 50目标共享每棵树的分裂结构 | 检验非线性和交互作用 |
| 八组Extra Trees | 按8个化学语义组训练 | 组内共享树结构 | 减少无关目标共享造成的干扰 |
| 单指标GBR | 50个独立模型 | 无，最后拼成50维画像 | 按论文任务形式复现单指标预测 |

Extra Trees调参网格为500棵树，`max_features`取0.3/0.6，`min_samples_leaf`取3/6，`max_depth`取无限制/8。GBR对每个指标分别使用5折网格搜索，以R²选参：树数100/300、学习率0.03/0.05、深度1/2、叶节最小样本8/15，并使用`sqrt`特征子集和0.8子采样抑制过拟合。

## 评价口径

- 训练目标是模型内部拟合的损失；调参准则只用于175个训练样本的5折选参；最终评价由统一评估器在75个测试样本上计算。
- 单指标GBR对每个感官指标独立拟合和选参；联合模型按整个多输出矩阵拟合或选参。两者最后都必须输出同顺序的 `75×50` 预测矩阵。
- 主总评分为 **Macro-RMSE**：先对每个感官指标计算测试RMSE，再对50个RMSE等权平均。辅助报告Macro-MAE、逐指标R²中位数和Spearman中位数。
- 0–6代理等级的MAE、准确率和Kappa只是展示层辅助指标，不用于确定主模型。
- 各模型的精确损失、输出权重和调参指标见 `docs/q1_modeling_spec.md`。

八个建模组为 `malt`、`hops`、`esters`、`mouthfeel`、`faults`、`spices`、`wild_fermentation`和 `overall`。

### 指标含义与公式

以下公式中：测试集样本数 $n = 75$，感官指标数 $J = 50$，第 $j$ 个指标的真实值为 $y_{ij}$、预测值为 $\hat{y}_{ij}$。除特别说明外，宏平均（Macro）指先对每个指标单独计算，再对 50 个指标取不加权算术平均，保证每个感官指标权重相同。

- RMSE（Macro-RMSE，均方根误差，主指标）

每个指标的预测误差平方均值的平方根，衡量预测值偏离真实值的典型幅度，量纲与原始感官评分相同：

$$\text{RMSE}_j = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_{ij} - \hat{y}_{ij})^2}, \qquad \text{Macro-RMSE} = \frac{1}{J}\sum_{j=1}^{J} \text{RMSE}_j$$

数值越小越好；全局均值基线为 0.5762，所有模型都需显著低于该值。

- MAE（Macro-MAE，平均绝对误差）

与 RMSE 类似但对离群误差不敏感（不开方、不平方）：

$$\text{MAE}_j = \frac{1}{n}\sum_{i=1}^{n}\left|y_{ij} - \hat{y}_{ij}\right|$$

- R²（决定系数，报告中取 50 个指标的中位数）

每个指标上，预测相对"直接用测试集均值"的方差改进比例：

$$R_j^2 = 1 - \frac{\sum_{i=1}^{n}(y_{ij} - \hat{y}_{ij})^2}{\sum_{i=1}^{n}(y_{ij} - \bar{y}_j)^2}$$

其中 $\bar{y}_j$ 为该指标测试集均值。$R^2 = 1$ 为完美预测，$0$ 等于均值基线，负值意味着不如均值。50 个指标的 R² 分布偏态明显，故报告中位数而非平均值。

- Spearman（秩相关系数，报告中取中位数）

将真实值与预测值各自转成秩（排名）后计算 Pearson 相关，衡量排序能力，与预测的尺度无关：

$$\rho_j = \text{Pearson}\left(\text{rank}(y_{\cdot j}),\ \text{rank}(\hat{y}_{\cdot j})\right)$$

对感官评分这类关心相对高低的任务，Spearman 是比 R² 更稳健的排序质量指标。

- 代理等级（proxy grade）

等级类指标先将连续分数转为 7 个等级（0–6）。分割点只用训练集学习：对每个指标取训练集的 6 个七分位数 $q_{1/7}, \dots, q_{6/7}$，真实值和预测值用同一组分割点离散化：

$$g_{ij} = \text{digitize}(x_{ij};\ q_{1/7}, \dots, q_{6/7}) \in \{0, 1, \dots, 6\}$$

- 等级MAE（grade MAE，宏平均）

等级上的平均绝对误差，反映平均偏离多少个感官等级：

$$\text{grade-MAE} = \frac{1}{J}\sum_{j=1}^{J}\frac{1}{n}\sum_{i=1}^{n}\left|g_{ij} - \hat{g}_{ij}\right|$$

- 精确准确率（exact accuracy）

等级完全命中的样本比例（宏平均）：

$$P(g_{ij} = \hat{g}_{ij})$$

- 相邻一级准确率（within-one accuracy）

等级误差不超过 1 的样本比例（宏平均），容忍边界样本的微小偏移：

$$P(\left|g_{ij} - \hat{g}_{ij}\right| \le 1)$$

- QWK（二次加权 Kappa，Cohen's kappa, quadratic weights）

等级一致性的机会校正度量：先由真实与预测等级的边缘分布构造"随机一致"的期望矩阵 $E$，再用二次权重惩罚越大的等级偏差：

$$w_{uv} = \frac{(u - v)^2}{(K-1)^2}, \qquad \text{QWK} = 1 - \frac{\sum_{u,v} w_{uv}\, O_{uv}}{\sum_{u,v} w_{uv}\, E_{uv}}$$

其中 $O$ 为观测混淆矩阵，$K = 7$。QWK = 1 为完全一致，0 等于随机水平（全局均值基线即为 0.0000），对序数型感官等级是比精确准确率更合适的综合指标。

## 结果分析与可视化

### 参数设定

| 模型 | 搜索空间 | 内部 CV 最优 |
|---|---|---|
| Ridge | alpha ∈ logspace(-3, 4, 40) | 366.5(区间内部) |
| PLS2 | n_components ∈ {2, 5, 10, 15, 20} | 10(区间中部) |
| MultiTask Elastic Net | l1_ratio ∈ {0.05–0.95},alpha ∈ logspace(-3, 0.5, 20),max_iter=30000 | alpha=0.248,l1_ratio=0.95;l1_ratio 处于网格上界,更稀疏的设定(如 1.0)可在后续尝试 |
| Extra Trees(全局/八组) | max_features ∈ {0.3, 0.6},min_samples_leaf ∈ {3, 6},max_depth ∈ {None, 8},500 棵树 | 多数组选 0.6 / 3,部分组选 depth=8;个别参数落在网格边界,含义是相邻值仍值得尝试,而非断言当前范围不当 |
| GBR(逐指标) | n_estimators × learning_rate × depth × min_samples_leaf 小网格 | 50 个指标分别选择;多数倾向较低学习率(0.03 占 37/50),浅树(深度 1–2) |

Elastic Net 在个别小 alpha 设定下迭代较多、,最终选定参数的模型在约 30 次迭代内收敛。
参数搜索方式和模型目标可以改进。

### 结果
在 75 个测试样本上,各模型 Macro-RMSE 为 0.488–0.498,相对全局均值基线(0.576)改善约 14–15%。Bootstrap(2000 次重采样)显示各模型的改善幅度置信区间明显重叠,即在当前样本量下,尚不足以认为头部模型之间存在可靠差异;Ridge 的点估计略低,但区间同样覆盖其他模型的点估计。PLS2 在四个代理等级指标(等级MAE、精确准确率、相邻一级准确率、QWK)上的点估计最高。

分指标看,排序能力(Spearman)较高的感官指标集中在酯类果香和野生发酵相关指标,香辛料及部分缺陷指标接近零。这一分布与"存在实测化学物质对应的感官指标更可预测"的方向一致,属观察性归纳。

对模型内部结构的检查给出一致的图景:PLS 的 VIP 头部变量为色度(EBC)、热量、pH、癸酸乙酯/乙酸乙酯类、乙醛、乳酸;八组 Extra Trees 的置换重要性中,各组最高特征与该组感官的常见化学载体相对应(麦芽香←色度、野生发酵←乳酸与 pH、酒花←萜烯类、香料←柠檬烯)。ester 组与 overall 组未观察到单一主导特征,前者呈现多物质共同作用的模式,后者或与整体评分的综合属性有关。需要说明的是,X4VG、乳酸等物质同时存在于特征侧与感官标签侧,相应结果宜表述为理化测量与感官评分的一致性,而非新的关联发现。

Elastic Net(l1_ratio=0.95)保留 227 个化学特征中的 85 个(约 37%),系数最强的保留特征包括乳酸、色度、热量、X4VG、发酵度(GFS)、异戊醇、柠檬烯、CO₂ 与两种乙酯。以 Ridge 系数、Elastic Net 保留强度、PLS VIP 与分组 Extra Trees 置换重要性四套排序的各自前 20 名计,有 13 个特征同时进入至少三套名单,集中于宏观酿造参数(色度、热量、pH、发酵度、CO₂)与发酵副产物(乙醛、乙酯类、高级醇、萜烯)两类变量。可预测性最高的感官指标(alcohol、bitterness、body、麦芽香总体)的响应曲线以单调为主,部分在高值区趋缓,个别呈非单调形状,提示线性模型可捕捉方向、树模型补充形状细节。
